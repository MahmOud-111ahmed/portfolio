01 — About

I build AI systems that ship

I'm Mahmoud Ahmed, an AI & Machine Learning Engineer who designs and delivers complete, production-oriented systems — not notebooks that stop at a metric. My work sits at the intersection of applied machine learning and backend engineering: I take a raw business problem, turn it into a working model, and wrap that model in an API, a database, and an interface people can actually use.

My workflow is consistent across every project: understand the business problem before touching data, clean and engineer features with intent, benchmark multiple algorithms instead of assuming one will win, and validate rigorously before deployment. From there I ship — typically with FastAPI or Flask backends, a proper database layer, and a role-based interface — so the result is a deployable product, not a proof of concept.

HemaSense is the clearest example: a full diagnostic platform where secretaries register patients, doctors enter lab values, a Decision Tree model flags a likely diagnosis, and an AI chatbot helps interpret the result — all backed by role-based access and an offline-capable database. LoanIQ is another: engineered financial ratio features, six benchmarked algorithms, and a Random Forest model deployed behind a live confidence score. Both were built to be used, not just demoed.

That's what I bring to a team: the ability to own an AI feature end-to-end — from business requirement to a live, reliable system in production.

HemaSense System

A full laboratory-report workflow: secretaries register patients, doctors fill in CBC values with normal-range guidance, and the platform runs a Decision Tree model to suggest a diagnosis before generating a shareable medical report.

Challenge

Hospitals still hand-write CBC reports and pass paper between the lab, secretary, and doctor — slow, error-prone, and impossible to search later.

Solution

Built a role-based FastAPI platform where secretaries register patients, doctors enter CBC values against reference ranges, and a Decision Tree model flags likely diagnoses before an AI chatbot helps interpret results.

Result

A working prototype covering the full patient journey — intake, diagnosis support, and an auto-generated, shareable medical report — with an offline MySQL database for clinics without reliable internet.

Loan Approval Prediction — LoanIQ

Applicants' income, assets, CIBIL score and loan terms feed a Random Forest model trained across 14 financial features, returning an approval decision with a live confidence score in under a second.

Challenge

Raw financial fields (income, assets, loan amount) don't separate approved from rejected applicants well on their own — the signal was hiding in the relationships between them.

Solution

Engineered ratio features — Total Assets, Loan-to-Income, Assets-to-Loan — then benchmarked six algorithms (Logistic Regression through XGBoost) with cross-validation and hyperparameter tuning.

Result

Random Forest generalized best across folds and was deployed in a responsive Flask app that returns a decision plus a confidence score in under a second.

Healthcare Predictive Analytics

Built to flag heart disease severity from patient vitals and history. The pipeline moved from raw, noisy clinical data through cleaning and feature engineering to a tuned XGBoost model, deployed in a Streamlit app doctors could use directly.

Challenge

Clinical datasets are small and noisy, so an overfit model would look great in testing and fail on new patients.

Solution

Focused on disciplined preprocessing and feature engineering first, then compared KNN and XGBoost with proper evaluation before picking a final model.

Result

A model with strong, consistent performance across evaluation metrics, wrapped in an interactive Streamlit app for real-time predictions.

Chocolate Sales Dashboard
